## 1. Custom Message Definitions (`eon_msgs`)

To interface natively with ROS 2, the package defines strongly typed message definitions under `eon_msgs`:

### 1.1 `eon_msgs/msg/EmotionObservation.msg`
Represents an uncertain perceptual observation from ERS (Emotion Recognition System):
```text
# Standard metadata header
std_msgs/Header header

# Unique observation identifier
string observation_id
string subject_id

# Primary emotion label (uncertain estimate)
string primary_emotion
float32 confidence              # [0.0 - 1.0]

# Continuous Affect Space (Circumplex Model)
float32 valence                 # [-1.0 (unpleasant) to +1.0 (pleasant)]
float32 arousal                 # [-1.0 (deactivated) to +1.0 (activated)]
float32 dominance               # [-1.0 (submissive) to +1.0 (dominant)]

# Multimodal Modality Weights
float32 facial_modality_weight
float32 voice_modality_weight
float32 gesture_modality_weight

# Uncertainty indicator
bool is_definitive_claim        # Always false (philosophical invariant)
```

### 1.2 `eon_msgs/msg/MotionProposal.msg`
Social motion proposal generated by ERG (Emotion Response Generation):
```text
# Standard metadata header
std_msgs/Header header

string proposal_id
string source_engine            # Usually "erg"

# Mandatory Non-Authoritative Invariant
bool is_authoritative           # Always FALSE. Must be checked by motion arbiter.
uint32 validity_duration_ms     # Lifetime before expiration

# Gaze and Head Kinematics Proposal
geometry_msgs/Vector3 target_gaze_direction
float32 head_pitch_rad
float32 head_yaw_rad
float32 head_roll_rad
float32 movement_velocity_scale # [0.1 - 1.0]

# Expressive Gesture / Light Ring Cue
string gesture_name             # e.g., "nod_gentle", "tilt_head", "neutral"
string expression_cue           # Light ring or display cue (e.g., "warm_white_breathe")
```

## 2. Standard Topic Namespace Catalog

| Topic Name | Message Type | Direction | Rate | Description |
|---|---|---|---|---|
| `/eon/sensors/camera/image_raw` | `sensor_msgs/msg/Image` | Ingress | 10–30 Hz | Robot camera feed |
| `/eon/sensors/audio/audio_data` | `audio_common_msgs/msg/AudioData` | Ingress | Continuous | Microphone PCM chunks |
| `/eon/ers/emotion_observation` | `eon_msgs/msg/EmotionObservation` | Egress | 5–15 Hz | Inferred emotional observation |
| `/eon/erg/motion_proposal` | `eon_msgs/msg/MotionProposal` | Egress | 5–10 Hz | Non-authoritative social motion |
| `/eon/diagnostics` | `diagnostic_msgs/msg/DiagnosticArray` | Egress | 2 Hz | Engine operational status |
